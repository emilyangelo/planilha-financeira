## 📌 Sobre o Projeto

Aplicação de **Controle Financeiro Pessoal** desenvolvida para gestão de receitas, despesas e organização do orçamento diário. 

O diferencial do projeto está na camada de controle de acesso: a aplicação conta com **sistema de login/cadastro administrativo (Admin)**, garantindo que os dados financeiros estejam protegidos e acessíveis apenas por usuários autorizados.

## 🚀 Funcionalidades Principais

- **🔐 Módulo de Autenticação (Admin):** Tela de login e cadastro com validação de credenciais para controle de acesso.
- **💵 Gestão de Entradas e Saídas:** Lançamento de receitas e despesas com categorização.
- **📊 Resumo Financeiro:** Visualização clara do saldo acumulado e fluxo de caixa.
- **🔒 Proteção de Dados:** Restrição de visualização das planilhas para usuários não autenticados.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3:** Interface e formulários de autenticação.
- **JavaScript:** Lógica de cálculos, validações e controle do fluxo de login.
